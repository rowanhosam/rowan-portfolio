الأفاتار اللي بيتكلم

ده مش فيديو أنا صوّرته. هو صورة واحدة ليا + تسجيل صوتي، والـ AI بيحرّك بُقّي وجسمي على الكلام.

محتاج إيه

  • صورة full body: واقف قدام الكاميرا، الخلفية سادة وفاتحة، والإيدين مرتاحين قدامك. كل ما الخلفية أنضف، كل ما شيلها بعدين يبقى أسهل.
  • تسجيل صوتك: Voice Memo عادي من الموبايل، ٥–١٠ ثواني بس. مثلاً: "Hi, I'm ___. I'm a software engineer."
💡 خلّي المقدمة قصيرة. أغلب الناس بيمشوا قبل ١٠ ثواني، والقصير كمان أرخص.

نعمل الفيديو

  1. افتح LongCat Avatar 1.5 على WaveSpeed واعمل أكونت. الأكونت الجديد بياخد كريدت صغير ببلاش يكفي تجربة.
  2. ارفع الصورة في image والصوت في audio.
  3. اختار 720p والصق البرومبت ده:
prompt
A person stands facing the camera in a bright, minimal studio with a plain light-grey background, speaking naturally and confidently to the viewer. Friendly expression, subtle smile, natural blinking, gentle head movements. Hands stay relaxed and clasped in front, with small natural gestures. Static camera, full body in frame, soft even lighting, photorealistic, sharp focus.

التكلفة: حوالي ‎$0.08‎ للثانية في 720p. يعني ١٠ ثواني ≈ ‎$0.80‎. جرّب ٥ ثواني الأول وبعدين اعمل الفيديو الكامل.

ليه البرومبت مكتوب كده؟ Static camera عشان الكاميرا ما تتحركش وتعرف تقص نفسك بعدين. Hands clasped لأن الإيدين أضعف حاجة في الموديلات دي، فلما تبقى هادية الغلطات ما تبانش.

نشيل الخلفية

عشان تبان واقف على الصفحة نفسها مش جوه بوكس.

الطريقة السهلة (من غير ما تشيل حاجة)

خلّي لون خلفية الموقع نفس لون الحيطة اللي في الفيديو بالظبط. افتح فريم من الفيديو، خد اللون بالـ color picker، وحطّه background للصفحة. ده اللي أنا عامله على الآيفون أصلاً.

الطريقة الاحترافية (فيديو شفاف)

  1. طلّع الفريمات من الفيديو بـ ffmpeg.
  2. شيل الخلفية من كل فريم بموديل اسمه BiRefNet (أو أداة rembg). ممكن تطلب من الـ AI يكتبلك سكريبت بايثون يعمل ده.
  3. جمّع الفريمات تاني في نسختين: WebM لكروم وHEVC لسفاري.
terminal
# 1) frames out
ffmpeg -i avatar.mp4 frames/%04d.png

# 2) remove background (pip install "rembg[cpu]")
rembg p frames/ cut/

# 3a) transparent WebM for Chrome / Android
ffmpeg -framerate 25 -i cut/%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 32 intro.webm

# 3b) transparent HEVC for Safari (Mac only)
ffmpeg -framerate 25 -i cut/%04d.png -c:v hevc_videotoolbox -alpha_quality 0.75 -tag:v hvc1 intro-hevc.mp4
⚠️ الآيفون مش دايماً بيشغّل الفيديو الشفاف. خلّي معاك نسخة MP4 عادية على لون الخلفية للآيفون، وخلّي الموقع يختار حسب الجهاز.

نبني الموقع مع AI

الموقع كله HTML + CSS + JavaScript من غير framework. أنا بنيته مع Claude Code كـ pair programmer: أنا بقرر الفكرة والتصميم، وبراجع وبجرّب كل حاجة. ولو حد سألك في انترفيو قول كده بصراحة، بس افهم كل جزء بيعمل إيه.

دي البرومبتات اللي تبدأ بيها. ابعت واحد واحد، وجرّب بعد كل خطوة:

🎬 الـ Hero

prompt
Build a single-page portfolio in plain HTML/CSS/JS. Hero: my transparent talking video (intro.webm, with intro-hevc.mp4 for Safari) standing full-body in the centre, my name huge and faded behind it, my title on the left, and a speech bubble on the right with live captions and a "Hear me" button that replays the video with sound. Autoplay muted on first visit only.

🔐 بوابة الدخول (الصفحة بتتغيّر على حسب الزائر)

prompt
Add an entry gate styled like an access pass. Visitors pick Recruiter, Engineer or Just curious, and recruiters also pick the role they're hiring for (full stack, front end, back end, design, AI). Reorder and highlight the page sections for that choice using CSS order and a config object, and support links like #recruiter-frontend.

🪪 الكارنيه اللي بيتحرك

prompt
Add an ID card hanging from a lanyard with realistic rope physics (Verlet integration, no libraries). I can drag and throw it, and clicking flips it in 3D to show the back. Add a holographic foil shine and a soft "clack" sound made with the Web Audio API.

🛂 أختام الإنجازات

prompt
Show my achievements as passport stamps with slightly rotated, ink-textured borders. Clicking a stamp scrolls smoothly to the full details of that achievement.

💻 الـ Terminal

prompt
Add an interactive terminal section where visitors type commands like help, skills, experience, projects and contact, with typed-out responses.
💡 ابعت للـ AI الـ CV بتاعك وقوله يكتب المحتوى منه. وراجع كل كلمة: هو ممكن يزوّد حاجات انت ما عملتهاش.

الشات اللي بيجاوب عنك

الزائر يسأل سؤال، والـ AI يرد عنك من معلوماتك، والرد بيطلع في فقاعة الكلام.

الجزءاستخدمت
السيرفرFastAPI (بايثون)
الموديلClaude Haiku: سريع ورخيص
المعلوماتملف profile.md فيه كل حاجة عني، والموديل يجاوب منه بس
الاستضافةRender (فيه خطة ببلاش)
prompt
Write a small FastAPI backend with one POST /ask endpoint that answers questions about me using Claude Haiku, based only on profile.md. Limit each visitor to 6 questions a day with slowapi, add a site-wide daily cap, allow CORS only from my GitHub Pages domain, read the API key from an environment variable, and add a render.yaml so I can deploy it on Render.
🔑 أهم حاجة: الـ API key ما يتكتبش أبداً في الكود ولا يترفع على GitHub ولا تبعته لحد. حطّه في الـ Environment Variables جوه Render بس. والـ rate limit هو اللي بيحميك من فاتورة كبيرة.
5

ننشر الموقع ببلاش

  1. اعمل repo جديد على GitHub وارفع فيه index.html وفولدر media.
  2. ادخل Settings ← Pages، واختار Deploy from a branch، والـ branch main.
  3. بعد دقيقة الموقع يبقى على username.github.io/repo-name.
💡 حط og:image في الـ <head> عشان لما تبعت اللينك على لينكدإن أو واتساب يطلع بصورة حلوة.

نعرف مين دخل

  • عدد الزوار: GoatCounter، ببلاش ومن غير cookies. سطر واحد في الصفحة.
  • إيميل لما حد يكتب اسمه: endpoint صغير في نفس سيرفر الـ FastAPI يبعتلك إيميل عن طريق Resend (فيه خطة ببلاش).
